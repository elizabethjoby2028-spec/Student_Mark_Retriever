# Student Mark Retriever

## Description
Student Mark Retriever is an Android application developed using Java and SQLite. It allows users to store student names and marks in a database and retrieve marks by entering the student's name.

## Features
- Add student names and marks.
- Store student details in an SQLite database.
- Retrieve marks using the student's name.
- Display a message if the student is not found.

## Technologies Used
- Java
- Android Studio
- SQLite
- XML

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Build and run the application on an emulator or Android device.
